# 週間自動制作・公開の要件

- 日本時間の曜日に対応する番組を、火曜と土曜は一人、その他は二人で制作する。12人の出演者は別の音声モデルを使う。
- 毎朝6時から Codex で台本を生成し、ローカルの AivisSpeech で音声を合成する。7時以降にローカルサイトと Cloudflare へ追加する。Mac が停止中は起動後に当日分を処理する。
- 番組の読みに従って台詞を合成し、台本・仮台本・音声・履歴を保存する。過去の同番組のテーマの繰り返しを避ける。記事を取り込まない場合は事実や実際の投稿を捏造しない。
- 音声生成に失敗した場合は配信しない。日付ごとに重複を避ける。公開サイトへの追加は認証必須。
- 既存のローカル音声は自動公開しない。声の配役は試聴に使用した組み合わせを初期値とする。
