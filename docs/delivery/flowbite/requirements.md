# Flowbiteでの全面刷新

ユーザーの「全面的」は大幅な変更を指す。従来のラベンダー色、サイドバー、ラジオの絵、カード配置を維持する小変更では満たさない。

1. daisyUIを外し、Flowbite本体と公式MCPを実際に導入・利用する。
2. ナビゲーション、情報の配置、番組カバー、色、文字組、プレーヤー、ライブラリ画面を刷新する。
3. 既存のMP3保存とAPI、あとで聴く・履歴・途中位置・ダウンロード・RSSを維持する。
4. 最新の通常エピソードを特集し、実際の音声を再生できること。空状態と試聴音声も区別する。
5. 「次に聴く」は実際の再生順を表示し、連続再生と倍速維持を確認する。
6. ライト・ダーク表示とスマホ幅に対応し、編集・MCP再利用・復旧手順を残す。
