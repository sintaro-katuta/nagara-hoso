# 利用体験の整理

2026-10-22。Flowbite版の色、アート、画面構成を維持し、初めて使う人が音声を探して聴き、手元のMP3を追加できるように整える。

- 情報整理担当：ファイルパス、API、開発構成、料金仕様、重複する装飾文を通常画面から外す。操作の名前と画面の内容を合わせる。
- 操作体験担当：空の検索結果から戻れること、保存状態が伝わること、実行できない再生操作が無効であること、ファイル選択と追加の状態が一貫すること。
- モバイル担当：音声の長さを選ぶ前に確認でき、再生・保存を押しやすく、フォームを読みやすくする。
- 統合担当：PCと390px幅で実操作し、隔離したライブラリで追加と再生を確認する。

公開、既存音声の削除・書き換え、生成ジョブやMCP設定の変更は対象外。
