# 利用者に必要な情報へ整理

既存の配色・カード・レイアウトを維持し、通常の聴取画面から開発者向け情報と重複する装飾文言を削除した。

- 「ライブラリ」は画面の実際の用途に合わせ「保存容量」へ変更。
- Cloudflare の将来構成、R2 の料金・無料枠、追加 API、README の案内、LOCAL PREVIEW 表示を通常 UI から削除。開発・運用については既存 README を参照。
- チャンネル、次に聴く音声、保存済みの容量など、利用者が操作するときに必要な見出しを日本語へ整理。ブランドとしてのアートワークは維持。
- 追加フォームの見出しと操作名を「音声を追加」に統一し、説明と出典を任意と明示。MP3 形式、100 MB の上限、この Mac に保存することは維持。
- 容量の計算は試算であり、音質の変更や自動削除はしないことを明記。

`public/index.html` の DOM ID と必須入力項目は維持。動的に生成される内部情報や操作名は `public/app.js` 担当と調整し、統合後にブラウザで確認する。
