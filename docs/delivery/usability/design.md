# 既存の見た目を保った使いやすさの改善

Flowbite の配色、カード、チャンネルのアート、固定プレーヤーは維持する。新しい装飾を足す代わりに、初めて使う人が「探す・聴く・あとで聴く・追加する」ための情報と操作を整える。

- 情報整理：開発用パス、API、将来のクラウド構成・料金、重複する装飾文を通常画面から削除。「ライブラリ」を実際の画面内容に合わせて「保存容量」へ変更。ローカル環境では受信に使いにくい RSS リンクは通常 UI から外し、配信機能自体は維持する。
- 操作：空の一覧や検索結果には次にできる操作を表示する。音声がないときの見かけ上の最新エピソードを隠し、再生できない操作は無効化する。保存の通知とボタン状態を一致させる。ファイルを選び直した場合は、自動入力したタイトルも更新する。
- モバイル：再生時間と出典を選択前に確認できるようにする。主な再生・保存操作を 44 × 44 px 以上にし、フォームの入力文字を 16 px にする。固定プレーヤーと一覧が狭い幅でも収まる構成を保つ。

DOM ID、音声追加 API、既存の保存データ形式は維持する。説明・出典は任意、MP3 形式・100 MB 上限・この Mac への保存は利用判断に必要な情報として残す。容量計算は将来の使用量の目安とし、特定サービスの無料枠との比較は表示しない。
