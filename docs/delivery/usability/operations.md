# ローカルでの確認と編集

通常の確認は `npm start` で起動し、`http://127.0.0.1:4317` を開く。今回の改善はローカルでの利用が対象で、公開や配信スケジュールの登録は行わない。

編集対象は `public/index.html`、`public/app.js`、`src/styles.css`。編集後は `npm run build`、`npm test` を実行する。生成される `public/styles.css` と `public/flowbite.js` は直接編集しない。

音声の追加や空状態を試すときは `node scripts/preview-fixture.mjs` を使う。4318 番の一時ライブラリで確認できる。終了時は Ctrl+C でサーバーを停止し、一時データを削除する。今回の検証用サーバーは停止・一時データ削除済み。既存の `data/` は検証用データで置き換えない。

UI 改善完了時の既存カタログは SHA-256 `d3b1bc7ffee596c5a605049d1493d80111c54f54d1bbac6bd75a0e6cc847d78c` と一致した。その後の別作業で Aivis 音声を 1 本追加したため、この値は現在のカタログではなく UI 改善時の照合記録。音声追加 API、RSS、将来の公開構成などの開発・運用情報は既存の README に保持する。今回の通常 UI ではこれらを表示しない。

ブラウザ保存の「あとで聴く」、再生履歴、再生位置は同じブラウザで利用するための状態。別のブラウザや端末への同期は追加していない。
