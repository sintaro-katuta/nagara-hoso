# AivisSpeechによる会話ラジオ

2026-10-22。音声生成はAivisSpeech本体に付属するローカルEngineを使う。接続先は127.0.0.1:10101、話速0.95。

- 阿井田 茂とまおのAIVMXを別の話者として使い、各台詞の担当を明記する。同じ話者のスタイル変更を複数人として扱わない。
- /speakersで実際のスタイルIDを解決し、/audio_query → /synthesisでWAVを生成する。指定モデルがなければ停止する。
- 短い相づち・問いかけ・反応と台詞間の間で会話を作る。合成後はMP3へ結合し、必要な場合だけ既存サイトへ追加する。
- 台本と音声を外部の音声合成APIへ送らない。PC内だけでAPIを利用する。
- 公式配布・利用条件を記録し、短いオリジナル会話を実際に合成して再生確認する。

この変更では記事の自動取得、日次ジョブ登録、30分の自動台本生成、一般公開は行わない。
