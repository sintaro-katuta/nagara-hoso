# Irodori-TTS試用

Irodori-TTSをこのApple Silicon Macで実行し、既存のAivisSpeech版と聴き比べられる二人会話を作る。

1. 公式コードと公式v4.1-Small-MFモデルを専用Python環境で使用する。
2. 声の説明から異なる男女2声を生成する。実在人物やAivisのキャラクター音声は参照に使わない。
3. 各話者の最初の合成音声を後続の参照にして、発言ごとの声のばらつきを抑える。
4. MP3生成、全編デコード、サイトからの再生を確認する。

今回は比較試作。既存サイトの画面・標準のAivisSpeech生成方法・自動配信設定は変更しない。
