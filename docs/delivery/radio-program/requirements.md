# AivisSpeechによる番組制作

ユーザーの聴き比べ結果を受け、以後の制作はAivisSpeechに統一。阿井田 茂とまお、話速0.95を使う。

1. 提示された構成を参考に、オープニング、フリートーク、お便り、曲・案内、エンディングの流れを持つ約5分の番組を実生成する。
2. 二人が相手の台詞を受けて会話する。台本は約1,600字のオリジナル。お便りは架空と音声内でも明示する。
3. タイトルコールの控えめなエコー、短いジングル、OP/EDの低いBGM、曲紹介後のオリジナル曲を実際に配置する。ト書きは読ませない。
4. 生の台詞、構成台本、実測のチャプター時刻、音素材を残し、合成なしでも音編集をやり直せるようにする。
5. 完成MP3をローカルサイトへ追加して再生を確認する。公開や実在のスポンサー告知は行わない。

参考：[筆先の世界の構成台本](https://hudesaki.com/freeradio)。参照したのは構成で、本文、架空のお便り、音楽は新規制作する。
