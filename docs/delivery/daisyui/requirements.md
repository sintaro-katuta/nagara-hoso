# daisyUIへのデザイン変更

ユーザー指定：daisyUIを使い、Blueprint MCPの導入も検討する。公開は引き続き行わない。

1. daisyUIを実際のnpm依存として導入し、ボタン・カード・タブ・入力欄・モーダル・プレーヤーの操作部を同ライブラリで構成する。
2. 日本語のラジオ棚として、PCとスマートフォンで再生と管理を操作できる。
3. 音声保存、API、検索、チャンネル、再生・途中位置を維持する。
4. CSSをローカルビルドし、外部CDNへの依存を追加しない。編集手順を残す。
5. Blueprint MCPの前提を公式ページで確認し、実行状況を明記する。未提供のライセンス情報を作らない。

追加する任意の体験：朝/夜/北欧のテーマ選択と、同じブラウザでの選択保存。
