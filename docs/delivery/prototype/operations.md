# ローカル運用

Node.js 22以上。`npm start` で127.0.0.1:4317、`PORT`で変更可。依存インストール不要。停止はCtrl+C。起動・既存音声の追加・バックアップ・復旧はREADME参照。

ヘルス確認：`curl --fail http://127.0.0.1:4317/api/health`。一覧APIの件数、data/episodes.jsonの件数と音声ファイルを確認。ログは起動したターミナルに出る。空きディスク不足の場合は追加が失敗し、成功扱いにせずエラー表示する。

復旧：停止 → バックアップのdataディレクトリに戻す → 起動。ソースの巻き戻しは元のソースコピーに戻す。今回データ移行・クラウド公開はない。JSONとMP3は同時トランザクションではないため、プロセス強制終了時に未登録ファイルが残る場合がある。データを確認してから手動整理する。再送は重複追加になる。

Cloudflare化は別工程：R2の契約とバケット作成、Workers/D1によるAPI、追加認証、RangeとRSSのHTTPS公開URL、上限監視、保存期間ルール。全て未実行。日次自動化は既存の生成ジョブ末尾にingestコマンドを足す方針で、この作業ではジョブ変更もスケジュール登録も行っていない。
