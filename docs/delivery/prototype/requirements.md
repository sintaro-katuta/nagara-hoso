# 要件

目的：Slackのスレッドから音声を探す手間を減らし、チャンネル別の番組をすぐ聴けること。

前提：新規ローカルプロジェクト。既存の音声生成器やSlackには接続しない。公開しない。生成済みMP3を受け取り、永続保存して再生する体験を完成させる。30分は制限にしない。

1. チャンネル別一覧、検索、並び順で番組を探せる。
2. MP3を画面とCLI/APIから追加し、再起動しても残る。
3. 実音声の再生、一時停止、シーク、倍速、スキップ、連続再生ができる。
4. あとで聴く・履歴・途中位置が同じブラウザで残る。
5. 容量を確認し、音質・本数・保存期間による概算を比較できる。
6. 日本語試聴サンプル、スマホ幅、RSSとダウンロードで体験を確認できる。
7. Cloudflare公開構成と既存生成器から追加する手順を残す。

今回の対象外：記事収集、台本の自動生成、30分番組の合成、実スケジューラー、Cloudflare契約・公開。利用モデルが不明のため既存のTTSを推測して変更しない。
