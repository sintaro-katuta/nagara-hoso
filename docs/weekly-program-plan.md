# ながら放送の週間番組と制作方針

更新日：2026年10月23日

曜日ごとに異なる番組とメインパーソナリティを設け、番組に合うテーマ選びから台本、音声制作、サイトへの追加まで自動で進める。聴いた後のフィードバックを次回以降に反映する。以下は企画の整理であり、週間スケジュールの自動実行はまだ設定していない。

## 決まった方針

- 音声制作はAivisSpeechのローカルEngineに統一する。Aivis Cloud APIは使わない。
- 曜日によって番組と主に話す人物を変える。その人物をメインパーソナリティと呼ぶ。
- 基本は2人の掛け合い。火曜の「熱血にぃやん」と土曜の「せっかくなんでゆっくりしていきまへんか」は1人番組とする。
- 土曜は、1人のおじさんがのんびり話す番組にする。
- 金曜はお金と暮らし、日曜は気持ちの振り返りを扱い、役割を分ける。
- 台本は自動生成し、人による事前レビューや承認待ちは挟まない。
- 名前・性格・立場・二人の関係はこれから決める。架空の人物として設定する。
- 番組の長さは30分に固定しない。毎朝7時は配信時刻の候補で、時刻・尺・保存期間は未確定。

## 週間番組表

| 曜日 | 番組 | 人数 | 主な話題 | 会話の方向性 |
| --- | --- | --- | --- | --- |
| 月 | 何でもマンデー | 2人 | 身近な疑問、雑学、最近気になったこと | 一つの疑問から自由に寄り道する |
| 火 | 熱血にぃやん | 1人 | 仕事や生活の悩み、小さな挑戦 | 自分の失敗も交えながら、聴き手の背中を押す |
| 水 | ミュージック・アワー | 2人 | 音楽の思い出、聴き方、音や曲にまつわる話 | 詳しい人と日常の感覚で聴く人が発見を交換する |
| 木 | テック・モック | 2人 | 技術、開発、日常で使う道具や仕組み | 技術を具体例で説明し、疑問や別の見方を返す |
| 金 | ゴールデンショウタイム | 2人 | 買い物、節約、給料、サブスク、貯金など | 金銭感覚の異なる二人が、何にお金を使うかを考える |
| 土 | せっかくなんでゆっくりしていきまへんか | 1人 | おじさんの体験談、生活の小話、脱線 | 急いで結論を出さず、話そのものを楽しむ |
| 日 | 気持ちのひとしお | 2人 | 一週間の出来事、気持ち、心に残ったこと | 無理に前向きにまとめず、言葉にしながら振り返る |

話題の具体例や会話の方向性は、人物設定と試聴後のフィードバックで育てる。月曜は幅広い発見、金曜は財布と暮らし、日曜は気持ちを軸にテーマを選び分ける。

## 自動制作の流れ

1. 日本時間の曜日から、その日の番組を選ぶ。
2. 番組の持ち味、出演者、二人の関係、定番コーナー、過去のフィードバックを読み込む。
3. 過去の放送履歴と照らし合わせ、まだ扱っていないテーマや違う切り口を選ぶ。前回と同じ結論・小話だけを繰り返さない。
4. 必要な材料を集める。記事を使う回は出典・日付・要点を保存し、人物の架空の体験談と区別する。
5. 構成と台本を生成する。独り語りと二人の掛け合いで、書き方を切り替える。
6. 出演者、構成の欠落、話題の重複、出典との整合などを自動で確認し、不備があれば修正・再生成する。人の承認待ちは設けない。
7. AivisSpeechで合成し、間、ジングル、必要なBGMを整えてMP3を書き出す。音声の欠落や破損も自動で確認する。
8. タイトル・紹介文と一緒にサイトへ追加し、台本、出典、使用した人物設定、音声、放送履歴を保存する。

失敗した日は未完成の音声を追加せず、既存の放送を残す。今回のドキュメント作成では、自動実行や外部公開は行わない。

## 台本の基本構成

オープニング → 短いフリートーク → メインの話題または定番コーナー → エンディングを基本とする。曲紹介や短い音楽は、番組に合う回に加える。全番組を同じコーナーで埋めない。

二人番組では、互いの発言を受けて質問・反応・具体例を返す。説明役と相づち役だけに固定せず、相方にも体験や意見を持たせる。一人番組では、聴き手への問いかけ、間、自分の考え直しで流れを作る。

架空のお便りを使う場合は架空のコーナーとして扱い、実際に届いた投稿とは言わない。架空の人物の経験は番組の創作設定として記録し、次回も整合させる。

構成の参考は[筆先の世界のラジオ用構成台本](https://hudesaki.com/freeradio)。台詞は番組ごとに作成する。実際の制作例は[小さな遠回りの台本](delivery/radio-program/script.md)。

## 番組と人物に保存する情報

| 対象 | 保存する内容 |
| --- | --- |
| 番組 | 曜日、番組名、話題の範囲、持ち味、出演人数、目安の尺、定番の流れ |
| 人物 | 架空の名前、関心、価値観、口調、癖、苦手なこと、過去に話した経験 |
| 二人の関係 | 互いの呼び方、共感する点、意見が違う点、会話の距離感 |
| 音声 | 人物に割り当てるAIVMXモデル、スタイル、話速、発音の調整 |
| 放送履歴 | 日付、テーマ、要点、出典、使った小話、前回からの続き |
| フィードバック | 対象回、対象番組または人物、気になった点、次回へ反映する方針 |

架空の人物と音声モデルは別々に管理する。モデルを替えても人物の性格や過去の話は維持する。候補は[人物像と音声モデルの候補](personality-and-voice-candidates.md)にまとめる。

## フィードバックの反映例

| フィードバック | 反映先 | 次回以降の変更例 |
| --- | --- | --- |
| にぃやんが説教っぽい | 火曜の人物設定 | 正論よりも、自分が失敗した話から入る |
| 二人とも同じ意見ばかり | その番組の関係性 | 無理な対立を作らず、体験や優先順位の違いを出す |
| 土曜はもっと脱線してほしい | 土曜の構成 | 結論を急がず、一つの小話を長めに話す |
| BGMが大きい | 音声制作の共通設定 | 次回からBGMを下げる |
| 今回の終わり方がよかった | その番組の構成 | 気に入った締め方を、次回の生成方針に残す |

通常はこれから作る回に反映し、配信済み音声の作り直しは別の指示として扱う。

## これから決めること

人物名と人物像、音声モデルの割り当て、番組ごとの尺、定番コーナー、配信時刻、テーマを集める範囲を決める。その後、週間番組表と自動制作を実装する。
